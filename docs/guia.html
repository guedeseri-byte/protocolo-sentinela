Guia do Protocolo Sentinela

Manual completo para instalar, configurar e usar o sistema.

O que é o Protocolo Sentinela?

O Protocolo Sentinela é um servidor offline brasileiro que reúne conhecimento essencial de preparação, sobrevivência e continuidade operacional. Ele funciona inteiramente no seu computador, sem depender de internet após a instalação.

Inclui:

  • Wikipedia offline em português
  • Assistente de IA local (funciona sem internet)
  • Biblioteca de livros e manuais técnicos
  • Protocolos de emergência curados
  • Cursos educacionais offline (Khan Academy, etc.)
  • Mapas offline do Brasil
  • Calculadoras, checklists e ferramentas de sobrevivência
100% gratuito e código aberto. Você pode instalar, modificar e compartilhar livremente.

Requisitos do sistema

  • Sistema operacional: Windows 10/11, macOS 12+ ou Linux (Ubuntu 20.04+)
  • RAM: 8 GB mínimo (16 GB recomendado para IA local)
  • Armazenamento: 50 GB livres (SSD recomendado)
  • Processador: Intel i5 / AMD Ryzen 5 ou superior
  • Docker Desktop: instalado e funcionando
  • Git: para clonar o repositório
  • Internet: apenas para baixar (após instalação funciona offline)
GPU é opcional mas recomendada para o módulo de IA local. Sem GPU, o assistente usa apenas CPU (mais lento, mas funcional).

Instalação passo a passo

1. Instale o Docker Desktop

Acesse docker.com/products/docker-desktop e baixe a versão para seu sistema. Instale e reinicie o computador se necessário.

Verifique se está funcionando:

docker --version

2. Instale o Git (se não tiver)

No Windows, baixe em git-scm.com. No Mac/Linux, geralmente já vem instalado.

3. Clone o repositório

Abra o terminal (PowerShell no Windows, Terminal no Mac/Linux) e execute:

git clone https://github.com/guedeseri-byte/protocolo-sentinela.git
cd protocolo-sentinela

4. Inicie o sistema

docker compose up -d

O Docker vai baixar todas as imagens necessárias. Na primeira vez pode demorar de 15 a 60 minutos, dependendo da velocidade da internet.

5. Acesse o sistema

Abra o navegador e vá para:

http://localhost

Você verá o painel principal do Protocolo Sentinela. Pronto!

Dica: Para parar o sistema, execute docker compose down. Para reiniciar, docker compose up -d novamente.

Primeiro acesso

Ao abrir http://localhost pela primeira vez, você verá:

  1. Painel de status — mostra quais módulos estão online
  2. Grid de módulos — acesso rápido a cada área do sistema
  3. Barra de busca — pesquisa em todos os módulos simultaneamente

Explore cada módulo no seu ritmo. Todo o conteúdo já está disponível localmente.

Assistente de IA local

O módulo de IA é uma das funcionalidades mais poderosas do Protocolo Sentinela. Ele roda 100% no seu computador usando:

  • Ollama — motor de execução de modelos de linguagem
  • Open WebUI — interface web para conversar com a IA
  • RAG (Retrieval-Augmented Generation) — a IA consulta os documentos locais para dar respostas mais precisas

O que você pode perguntar

  • "Como purificar água em emergência?"
  • "Quais são os protocolos de primeiros socorros para queimadura?"
  • "Como montar um kit de 72 horas?"
  • "Explique técnicas de preservação de alimentos"
Sem GPU: A IA funcionará, mas as respostas serão mais lentas (30-60 segundos). Com uma GPU NVIDIA compatível, as respostas chegam em poucos segundos.

Uso 100% offline

Após a instalação, o sistema não precisa de internet para nada. Todos os dados estão armazenados localmente:

  • Wikipedia é armazenada em formato ZIM (~10 GB para PT-BR)
  • Modelos de IA ficam salvos no diretório do Ollama
  • Cursos e livros são baixados na instalação
  • Mapas são armazenados em tiles locais

Você pode literalmente desconectar o cabo de rede e tudo continuará funcionando.

Ideal para: áreas rurais, embarcações, cabanas, bunkers, ou qualquer situação onde a internet não esteja disponível.

Como atualizar

Quando houver uma nova versão disponível:

cd protocolo-sentinela
git pull origin master
docker compose down
docker compose up -d --build

Isso baixa as últimas alterações e recria os containers com as novidades.

Problemas comuns

Docker não inicia

  • Reinicie o computador após instalar o Docker Desktop
  • No Windows, verifique se o WSL2 está habilitado: wsl --update
  • Verifique se a virtualização está ativada na BIOS

"Porta 80 já está em uso"

Outro programa está usando a porta 80. No Windows, geralmente é o IIS ou o Skype. Pare o serviço conflitante ou altere a porta no docker-compose.yml.

Sistema muito lento

  • Verifique se o Docker tem memória suficiente alocada (mínimo 4 GB)
  • Use SSD em vez de HDD para melhor desempenho
  • Feche programas pesados enquanto usa a IA local

IA não responde

  • Verifique se o container do Ollama está rodando: docker ps
  • Confirme que o modelo foi baixado: docker exec ollama ollama list
  • Sem GPU, a primeira resposta pode levar até 2 minutos

Perguntas frequentes

Preciso de internet para usar?

Não. A internet é necessária apenas uma vez, durante a instalação. Depois disso, tudo funciona offline.

Posso instalar em um Raspberry Pi?

O sistema completo é pesado para um Raspberry Pi, mas módulos individuais (como a biblioteca e os protocolos) podem ser adaptados para hardware mais leve.

O projeto é gratuito?

Sim, 100% gratuito e de código aberto sob licença MIT. Você pode usar, modificar e redistribuir livremente.

Como posso contribuir?

Acesse o repositório no GitHub, abra issues com sugestões ou envie pull requests com melhorias.

Posso usar em uma rede local?

Sim! Outros dispositivos na mesma rede podem acessar o sistema usando o IP da máquina host em vez de localhost. Exemplo: http://192.168.1.100.
